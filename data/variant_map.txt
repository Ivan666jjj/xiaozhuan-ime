# 篆字补字映射：现代通行字 → 有篆形的古字（异体/古今字）
#
# 为什么需要：字体收的是《说文》字头，而现代人打的是通行字形。
#   例：「他」不在《说文》字头里，《说文》人部作「佗」—— 所以打「他」
#   要指向「佗」的篆形，否则编辑器回退成楷体，看着就不是篆书了。
#
# 格式：现代字 <TAB> 古字
#
# 来源与复核状态（重要）
#   候选来自 Unihan 18.0 的 kSemanticVariant / kZVariant，但那张表把
#   「只是同音」的字也标了进来（如 你→祢、孰→塾），所以 **逐条人工过了一遍**。
#   筛选条件：同部首 + 同音 + 语义确实相同/同源。
#   剔除了 15 条（吨→啍、嘴→咀、愈→愉、搬→搫 等），理由见 commit。
#
#   ⚠️ 本表未经古文字专业审阅。如发现错误，删掉对应行重建即可。

# 他 → 佗：《说文》人部「佗，負何也」，「他」是后起的假借字。
