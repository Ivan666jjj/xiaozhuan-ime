# 小篆输入法 · Rime 方案（Windows / 安卓）

在 Windows 和安卓上用**同一份数据**打出小篆。macOS 版是原生输入法（体验更完整），
这里走 [Rime](https://rime.im/) 引擎 —— 不用写代码，只装配置。

## 更省事的装法：东风破一行命令

如果你已经装了 Rime（小狼毫 / 同文），可以直接用东风破（plum）：

```bash
bash rime-install Ivan666jjj/rime-xiaozhuan
```

它会自动把方案文件放好（**但不会覆盖你已有的方案列表** ——
要启用还得按下面的步骤做一次，或者往自己的 `default.custom.yaml` 里加
`schema_list/+:`）。本仓库就是那个独立仓库的源，两边内容一致。

> ⚠️ 注意：`schema_list/+` 里的 **`/+` 不能省**。Rime 的 patch 默认是
> 「整体替换」，少了 `/+` 会把你原有的方案列表清空。

## 先拿到文件

**去 Release 页下载**（别用仓库里的源码，那里面没打包字体）：

```
https://github.com/Ivan666jjj/xiaozhuan-ime/releases/latest
    → xiaozhuan-ime-Rime-v1.0.0.zip
```

> 🌏 **打不开 github.com？** 在网址前面加上 `ghfast.top/` 即可：
> `https://ghfast.top/https://github.com/Ivan666jjj/xiaozhuan-ime/releases/latest`

解压后就是下面「文件清单」里的那几个文件（含字体）。也可以从源码构建：
`./build.sh publish` 会把两个平台的包一起打出来。

## 原理：跟 macOS 版一模一样的思路

**上屏的是普通汉字，靠字体把候选窗渲染成篆形。**

- 你装了 `ShuowenSeal.ttf` → 候选窗里看到**篆书**
- 别人没装 → 看到**楷体汉字**，照样读得懂

所以打出来的字**可以复制、可以分享、可以搜索**，不会因为换台电脑就变豆腐块。

## 文件清单

| 文件 | 作用 |
|---|---|
| `shuowen.schema.yaml` | 输入方案（含候选窗字体设置） |
| `shuowen.dict.yaml` | 词典：408 个拼音音节 / 8,631 个篆字 |
| `default.custom.yaml.example` | **参考样例**，看它怎么把方案挂进列表 |
| `recipe.yaml` | 东风破（plum）配方 |
| `trime.custom.yaml` | 安卓端：指定候选窗字体 |
| `ShuowenSeal.ttf` | 篆书字体（25.8 MB） |

> 全部由 `python3 tools/export_rime.py` 生成，改词典要重跑那个脚本。

## Windows：小狼毫（Weasel）

**① 装输入法**

从 [rime.im/download](https://rime.im/download/) 下 **小狼毫（Weasel）**，装好。

**② 装字体**

右键 `ShuowenSeal.ttf` → **为所有用户安装**。
（不装也能用，只是候选窗显示楷体。）

**③ 放配置**

右键任务栏的小狼毫图标 → **用户文件夹**（会打开 `%APPDATA%\Rime`），把
`shuowen.schema.yaml`、`shuowen.dict.yaml` 两个文件复制进去。
（要让「小篆」出现在方案选单里，参考 `default.custom.yaml.example`，
在**你自己的** `default.custom.yaml` 里加两行 `schema_list/+:`）

**④ 重新部署**

右键图标 → **重新部署**（等它转完，词典 8,631 条要跑几秒）。

**⑤ 切换**

按 **Ctrl + `**（反引号）或 **F4** 打开方案菜单，选「**小篆**」，然后敲拼音即可。

> **候选窗还是楷体？** 说明字体没装上，或者 `font_face` 名字对不上。
> 确认字体在「设置 → 个性化 → 字体」里显示为 **Shuowen Seal**。改完字体要**重新部署**一次。

## 安卓：同文输入法（Trime）

**① 装输入法**

从 [GitHub Releases](https://github.com/osfans/trime/releases) 或应用商店装 **同文输入法**。

**② 放字体（安卓装不了系统字体，所以给 Trime 单独准备一份）**

1. 打开同文输入法 → **配置管理 → 用户文件夹**（一般是 `/storage/emulated/0/rime`）
2. 在里面**新建一个 `fonts` 文件夹**（注意必须叫这个名字）
3. 把 `ShuowenSeal.ttf` 复制进 `rime/fonts/`

**③ 放配置**

把 `shuowen.schema.yaml`、`shuowen.dict.yaml`、`trime.custom.yaml`
复制到 `rime/` 目录（跟 `fonts` 同级）。

**④ 部署**

同文输入法 → **配置管理 → 重新部署**。

**⑤ 启用**

系统设置 → 语言和输入法 → 启用「同文输入法」并切换过去；
在同文里按方案菜单选「**小篆**」，敲拼音。

> **候选窗还是楷体？** 三个常见原因：
> ① 字体没放进 `rime/fonts/`（或文件夹名字写错）；
> ② `trime.custom.yaml` 里的文件名跟实际文件**不完全一致**（大小写、扩展名都算）；
> ③ 放完没重新部署。
>
> **装了小狼毫又想在安卓上用**：两个平台的配置基本通用，只是安卓多需要
> `trime.custom.yaml` 和 `rime/fonts/` 那一步（安卓不允许随意装系统字体）。

## 两个平台的差异一览

| | Windows（小狼毫） | 安卓（同文） |
|---|---|---|
| 候选窗字体键名 | `style/font_face` | `style/candidate_font` |
| 字体怎么装 | 右键安装到系统 | 放进 `rime/fonts/` |
| 配置目录 | `%APPDATA%\Rime` | `/storage/emulated/0/rime` |
| 生效方式 | 重新部署 | 重新部署 |

## 覆盖率：哪些字打不出篆形

字体只收《说文》系统里的篆形，**不是每个现代汉字都有**。实测：

| 范围 | 有篆形 |
|---|---|
| **人名常用字** | **97%**（71/73） |
| **百家姓（前 60）** | **94%**（56/60） |
| GB2312 常用字 | 70.6%（4,775 / 6,763） |

**没篆形的大致四类**：

| 类型 | 例子 | 说明 |
|---|---|---|
| **后起字** | 娜、辉、估、住、花 | 《说文》成书时还没有 |
| **古今字** | 他（《说文》作「佗」）、你（本字「爾」） | 篆形挂在古字头下 |
| **异体字** | 丐→匃、坑→阬、碗→盌 | 篆形在异体字那一笔 |
| **超 BMP 字头** | 㐹、㑂、𠆺 | 在扩展 B/C 区，本字体是 BMP 设计 |

**打不出来时不会变豆腐块** —— 会 fallback 到系统字体，**显示成楷体**。
所以打「娜」出来的是普通的「娜」，一眼能看出这个字没有篆形。

## 键盘用法

| 按键 | 作用 |
|---|---|
| 拼音字母 | 输入（如 `shui`） |

| 空格 | 选第一个候选 |
| `Ctrl + \`` / `F4` | 切换输入方案 |
| `Shift` | 临时切到西文 |

## 已知限制（跟 macOS 版比）

- **候选窗样式是 Rime 的**，不能像 macOS 版那样自绘（那边字号、每行候选数都能调）
- **候选窗里的篆形依赖字体**：安卓上如果字体没放对，看到的就是楷体
- **词典只有单字**（8,631 个），没有词组联想 —— 这也是 macOS 版的行为，保持一致

## 字形来源与授权

**分发包里的字体不含汉典字形**（汉典授权仅到「个人使用」，对外分发必须排除）。

字形来自两处：

| 来源 | 授权 | 占比 |
|---|---|---|
| **开元小篆** | SIL OFL 1.1 | ~87% |
| **台湾全字库说文解字** | 政府资料开放授权条款第 1 版 | ~13% |

授权全文见包内 `KaiyuanSeal-OFL.txt` 与 `字形来源与授权.md`。

> ⚠️ **自己从源码构建**时，默认会用到汉典的补缺字形（多出 1249 个字）。
> 那种版本**只能自用**；对外分发请用 `./build.sh publish`，
> 它会自动改用不含汉典的合规字体重建。
