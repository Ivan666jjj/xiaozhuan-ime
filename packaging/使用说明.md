# 小焕的小篆输入法 · 使用说明

macOS 上的小篆输入法：**打拼音出汉字，把字体一换就显示成篆书**。

> 为什么不是直接打出篆字？因为篆书字符在 Unicode 里属「超 BMP」区，
> 别人的电脑没装对应字体就是一片方块，发出去谁也看不了。
> 所以这里打成**普通汉字**，靠字体显示篆形 —— 对方没装字体也还能读，
> 装了（或文档内嵌了字体）就是篆书。

---

## 一、安装（四步，第三步别漏）

### 1. 解压

把 `小焕的小篆输入法-macOS.zip` 解压到任意位置（比如桌面）。

### 2. 运行安装脚本

打开「终端」，把解压出来的文件夹拖进终端窗口，然后执行：

```bash
cd <刚才拖进来的文件夹路径>
./install.sh
```

脚本会自动做三件事：把输入法装进 `~/Library/Input Methods/`、把字体装进
`~/Library/Fonts/`、并把它注册进系统。

### 3. ⚠️ 注销重新登录（**第一次安装必须做**）

**这一步不能省。** macOS 有个硬限制：

> 一个在**本次登录会话开始时**还不存在的输入法，怎么折腾都不会出现在输入法菜单里。

重启电脑也行（等同于注销重登）。**而且只需要这一次** —— 以后我更新这个输入法，
你直接重跑 `./install.sh` 就生效，不必再重登。

### 4. 在系统设置里加上它

**系统设置 → 键盘 → 文字输入 → 输入法 → 编辑**，在列表里找到
「**小焕的小篆输入法**」并添加。

> 如果这一页里**看不到它**：把「系统设置」完全退出再重开一次（那个面板读缓存）。
> 还看不到就先确认第 3 步做了没有。

---

## 二、开始打字

1. 按 **Ctrl + Space**（或点菜单栏右上角的输入法图标）切到「小焕的小篆输入法」
2. 敲拼音，比如 `shui`
3. 候选窗会弹出**篆形**的候选，下面标着对应的现代汉字
4. 按 **数字键** 或 **空格** 选字上屏

| 按键 | 作用 |
|---|---|
| 拼音字母 | 输入 |
| `1` ~ `9` | 选第 N 个候选 |
| 空格 | 选第一个候选 |
| `-` / `=` | 上下翻页 |
| 回车 | 直接上屏拼音原文 |
| Esc | 清空 |

> 简体字也能打：「边」会自动对应到「邊」的篆形（篆书本来就不分简繁）。

---

## 三、⚠️ 让它显示成篆书（关键一步）

**上屏的是普通汉字**。要让它在 Word / WPS / 备忘录里**看起来是篆书**，
必须把这段文字的**字体设成 `Shuowen Seal`**：

1. 选中你打的那些字
2. 在字体框里输入 `Shuowen`（Word/WPS 里它可能被归到「西文字体」那一栏）
3. 选中 `Shuowen Seal` —— 字就变成篆书了

**不设字体会怎样？** 字还是正常的汉字（可读，但不是篆形）。这是设计如此，
不是坏了 —— 好处是**发给别人、对方没装字体时也还能读**。

---

## 四、调整候选窗

输入法没有 Dock 图标，设置从**菜单栏的输入法图标**进：

1. 点菜单栏右上角的输入法图标（显示「拼」或「A」或地球）
2. 选「**偏好设置…**」

可以调：

| 项目 | 范围 |
|---|---|
| 候选字号 | 20 – 120 pt |
| 每行候选数 | 5 / 6 / 7 / 8 / 10 / 12 |
| 候选下方是否显示对照汉字 | 开 / 关 |

窗口里有**实时预览**，改完立刻生效（正开着的候选窗会马上重排，不用重启）。

同一个菜单里还有「放大候选字 / 缩小候选字 / 恢复默认字号」三个快捷项。

> 还没重登、切不到输入法时，也可以在终端里直接开设置窗口：
> ```bash
> "$HOME/Library/Input Methods/小焕的小篆输入法.app/Contents/MacOS/ShuowenIME" --prefs
> ```

---

## 五、想发给别人看篆书？

普通分享（微信发文档、邮件附件）**对方没装字体就只能看到汉字**。
要保证对方也能看到篆形，用项目里的工具把字体**嵌进 .docx**：

```bash
python3 tools/embed_font_docx.py 你的文档.docx
# 生成 你的文档_嵌入字体.docx
```

Word / WPS 打开这种文档时会从文件里加载字体，**对方什么都不用装**。
（字体只嵌入文档里用到的那几个字，所以文档不会变大多少：13 MB 的字体子集后约 60 KB。）

---

## 六、卸载

```bash
./install.sh --uninstall
```

会移除输入法和字体。之后到系统设置的输入法列表里也把它删掉即可。

## 常见问题

**Q：输入法菜单里找不到它／切不过去。**
A：见「安装」第 3 步 —— 首次安装**必须注销重登**。这不是 bug，是 macOS 的限制：
本次登录会话开始时不在输入源列表里的输入法，重启服务、重新注册都没用，
只有注销重登（或重启）才认。重登后在系统设置里手动添加一次即可。

**Q：打出来的字是方块 / 空的。**
A：这段文字的字体没设成 `Shuowen Seal`。见第三节。

**Q：某个字打不出来。**
A：篆形来自《说文解字》，共收录约 9,400 字。**后起字**（「他」「你」「们」「做」
「花」「泪」等）《说文》本来就没有，所以打不出来 —— 这是数据源的限制，
不是输入法出错。

**Q：候选窗太大了／太小了。**
A：见第四节，字号可调。

**Q：能打多少字？**
A：约 9,400 个篆形；常用字（约 5,200 字）覆盖 **77%**。

**Q：装完要重登，那我以后每次更新都要重登吗？**
A：不用。只有**第一次**安装需要，之后原地更新直接生效。

## 附：字形来源与授权

字形来自两处，已在字体元数据和 `data/glyph_coverage.json` 里注明：

- **主字形**：台湾「**全字库说文解字**」（数位发展部 CNS11643），
  依《政府资料开放授权条款 - 第 1 版》释出，**个人与企业均可免费使用**。
  使用时请保留来源标注：
  > 数位发展部，CNS11643 中文标准交换码全字库网站，https://www.cns11643.gov.tw
- **补缺字形**：汉典（zdic.net），**授权仅到个人使用**。

**要对外分发或商用**，请用纯全字库版重建（不含汉典字形）：

```bash
python3 font/build_font.py --no-zdic
```

> 另外说明一点：本项目对字形做的是**归一化、加粗、重编码**等技术处理，
> 不构成新的独创性表达，因此**不能主张对字形的著作权**。
> 对应的司法观点见北京知识产权法院「汉仪诉子盟案」：仅笔画加粗不构成改编。
> 但**输入法程序、构建脚本、简繁映射表**这些是项目自己的成果。
